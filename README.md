# 🏥 Hospital Inteligente — Sistema de Informação Integrado e Seguro

[cite_start]Este repositório contém o projeto de desenvolvimento técnico e a documentação científica para a cadeira de **Sistemas de Informação**, do Curso de **Engenharia Informática** no **ISCTEM** (Instituto Superior de Ciência e Tecnologia de Moçambique). 

[cite_start]O projeto foi concebido sob o tema geral: *"Concepção Estratégica e Desenvolvimento de um Sistema de Informação Empresarial Inteligente para Transformação Digital Organizacional"*, simulando o modelo de atuação de uma empresa de consultoria em Engenharia de Software[cite: 2, 6].

## 🧬 Sobre o Projeto
[cite_start]O objetivo principal desta proposta é mitigar e resolver os problemas clássicos de gestão hospitalar tradicional, tais como a perda de informação, atrasos em processos clínicos, fraca comunicação interdepartamental e a ausência de suporte tecnológico para decisões de caráter estratégico[cite: 3, 5]. 

[cite_start]Através de uma abordagem sociotécnica [cite: 10][cite_start], o sistema integra perfeitamente os fluxos operacionais, táticos e estratégicos da organização. [cite_start]O resultado é a transformação da instituição num **Hospital Inteligente** altamente competitivo, eficiente, seguro e em total conformidade com as normas éticas e legais de proteção de dados de saúde[cite: 4, 12, 20].
