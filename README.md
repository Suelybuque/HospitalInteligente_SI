# 🏥 Hospital Inteligente

### Sistema de Informação Integrado, Seguro e Inteligente

Este repositório contém a documentação técnica e o protótipo desenvolvido para a disciplina de **Sistemas de Informação**, do curso de **Engenharia Informática** no **ISCTEM – Instituto Superior de Ciência e Tecnologia de Moçambique**.

O projeto foi concebido no âmbito do tema:

> **"Concepção Estratégica e Desenvolvimento de um Sistema de Informação Empresarial Inteligente para Transformação Digital Organizacional"**

A solução proposta simula a atuação de uma empresa de consultoria em Engenharia de Software na modernização completa dos processos hospitalares.

---

## 📖 Sobre o Projeto

Os hospitais tradicionais enfrentam diversos desafios operacionais e administrativos, incluindo:

* Perda de informação;
* Atrasos em processos clínicos;
* Falhas na comunicação entre departamentos;
* Gestão ineficiente de recursos;
* Ausência de suporte tecnológico para tomada de decisões estratégicas.

Para responder a estes desafios, foi concebido um **Sistema de Informação Hospitalar Inteligente**, capaz de integrar processos operacionais, táticos e estratégicos numa única plataforma.

### 🎯 Objetivos

* Centralizar a informação clínica e administrativa;
* Melhorar a comunicação interdepartamental;
* Automatizar processos críticos;
* Apoiar a tomada de decisões através de dashboards e relatórios;
* Garantir segurança, privacidade e conformidade com normas de proteção de dados;
* Promover a transformação digital da instituição.

---

## 🏗️ Arquitetura do Sistema

O sistema foi projetado segundo uma abordagem sociotécnica, integrando:

### Operacional

* Gestão de pacientes
* Gestão de consultas
* Registos clínicos eletrónicos
* Farmácia
* Laboratório

### Tático

* Gestão de recursos humanos
* Gestão financeira
* Gestão de inventário
* Indicadores de desempenho

### Estratégico

* Business Intelligence
* Dashboards executivos
* Análise preditiva
* Apoio à tomada de decisão

## 🚀 Como Executar o Protótipo

### 1. Clonar o Repositório

```bash
git clone https://github.com/seu-utilizador/hospital-inteligente.git
```

### 2. Entrar no Projeto

```bash
cd hospital-inteligente
```

### 3. Executar o Backend

```bash
cd src/backend
npm install
npm start
```

### 4. Executar o Frontend

```bash
cd src/frontend
npm install
npm run dev
```
